# Pilot 001 — Outreach message (not sent)

Subject: Request for independent technical review — small reproducible data-processing pilot

Hello,

I'm developing Carbon Mirror, an open methodology for examining avoidable digital infrastructure waste. Before making claims about its usefulness, I'd like to test it against conventional data-engineering review.

We've built a synthetic data-processing workload that can be executed and independently verified on GitHub Actions. We're seeking experienced data engineers and applied-computing practitioners for a bounded review: approximately 30 minutes of orientation and 90 minutes of independent assessment, followed by written findings. The objective is to identify valid opportunities and trade-offs—not to endorse the project. A finding that Carbon Mirror adds no value is an entirely acceptable outcome.

The project and initial research code are public:
https://github.com/carbon-mirror-project/carbon-mirror-pilots

We'd agree in advance on scope, compensation (if available), attribution/anonymity and handling of unpublished reviewer findings. Reviewer assignments and materials will be finalized only after preregistration.

If this is of interest, I'd appreciate a reply describing your relevant experience and any conditions for participating. If you aren't available, a suggestion for an independent reviewer would also be helpful.

Thank you,
The Carbon Mirror Project
